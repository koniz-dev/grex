# Pre-Deployment Checklist

Things that **must** be settled before the first production build hits a
public app store or hosting service. Each item is currently a placeholder
or unset in the repo; the build/dev loop works today, but submission will
be rejected (Play Store / App Store reject `com.example.*` package names,
Firebase config points at the placeholder project, etc.).

Tick items off as they get resolved — keep this file in sync with reality.

---

## 1. Choose a real application / bundle identifier

**Status:** ❌ Not set. All targets use the Flutter default
`com.example.grex`, which Google Play and the App Store reject on
submission.

**Decide first:**

- Pick a reverse-domain identifier you actually own or control, e.g.
  `dev.koniz.grex`, `vn.vtii.grex`, `com.koniz.grex`. The chosen value
  becomes the immutable Android `applicationId` and iOS `bundleId` for
  the app's whole life on the stores, so this is a one-shot decision.

**Then update every occurrence of `com.example.grex`:**

- [ ] `android/app/build.gradle.kts` — `namespace`, `applicationId`
      (line 13 + 28). The `// TODO: Specify your own Application ID` on
      line 27 is the original Flutter scaffolding hint.
- [ ] `android/app/google-services.json` — `package_name`. Don't hand-edit;
      re-download from Firebase (see step 2).
- [ ] `android/app/src/main/kotlin/com/example/grex/MainActivity.kt`
      — rename the directory path **and** the `package` declaration on
      line 1 to match the new identifier.
- [ ] `ios/Runner.xcodeproj/project.pbxproj` — 6 occurrences of
      `PRODUCT_BUNDLE_IDENTIFIER` (3 for the app, 3 for RunnerTests; the
      RunnerTests entries get a `.RunnerTests` suffix).
- [ ] `ios/ExportOptions.plist` — line 23.
- [ ] `ios/fastlane/Appfile` line 18 + `ios/fastlane/Fastfile` line 14
      (both already carry `# TODO: Update to match your bundle ID`).
- [ ] `.github/workflows/deploy-android.yml` — `packageName:` inside the
      commented-out `Setup Google Play` step.

> Tip: do a project-wide find/replace from `com.example.grex` to the new
> identifier first, then rename the Kotlin directory by hand
> (`android/app/src/main/kotlin/com/example/grex/` → mirroring the new
> reverse-domain path) and run `flutter clean && flutter pub get`.

## 3. Store accounts and signing material

**Status:** ❌ No keystores or certificates are tracked in the repo (correct
behaviour); none are wired into CI yet either.

### Android (Google Play)

- [ ] $25 one-time Google Play Developer account.
- [ ] Generate upload keystore once and store it offline:
      ```bash
      keytool -genkey -v -keystore upload-keystore.jks \
        -keyalg RSA -keysize 2048 -validity 10000 -alias upload
      ```
- [ ] Create the app in Play Console with the new package name.
- [ ] Create a service account with **Release Manager** role, download
      its JSON key — used for `GOOGLE_PLAY_SERVICE_ACCOUNT_JSON` secret.

### iOS (App Store)

- [ ] $99/year Apple Developer Program membership.
- [ ] Distribution certificate exported from Keychain as `.p12`
      (password-protected).
- [ ] App Store Connect API key (Users and Access → Integrations → Keys),
      download the `.p8` file once.
- [ ] App record in App Store Connect with the new bundle ID and at
      least one TestFlight build slot.
